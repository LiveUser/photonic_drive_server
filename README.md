# photonic_drive_server

Self Hosted Cloud Drive.

## Download the compiled apps
- [Client](https://github.com/LiveUser/photonic_drive/releases)
- [Server](https://github.com/LiveUser/photonic_drive_server/releases)

## Server instructions
1. Download the compiled app
2. Estract the downloaded .zip file
3. Move the extracted folder into a place where you won't delete it (somewhere permanent)
4. Go inside the folder and run the executable file
5. Pick a folder for your data and the database to be stored
6. Enter the port where you want the server to run
7. Tap "Start Server"
8. Create an access token. You will need it to access your server
---------------------------------------------------------------------------------------------
9. Download and install a software like Ngrok
10. Follow the instructions to setup a tunnel in order to expose your server to the internet

Note: In order for a server to do its job, the computer running it must be powered on and connected to the internet 24/7.

## Client instructions
### Windows
1. Download and install the windows .zip
2. Extract the .zip
3. Move the extracted folder into a place where you won't delete it (somewhere permanent)
4. Go inside the folder and run the executable file
5. Enter the required fields
6. Enjoy your own cloud

### Android
1. Download and install the .apk
2. Open the app
3. Enter the required fields
4. Enjoy your own cloud

Note: Client must also be connected to the internet in order to be able to access the server.
